How this page works

 

A pilot logbook records each flight across two facing pages: a left-hand page (date, aircraft, route, landings) and a right-hand page (night/instrument/cross-country hours, pilot-in-command time, remarks) for the same flights. Photographing the two sides separately turned out to be hard to keep paired up — a right-hand page carries no date, so matching it back to the correct left-hand page after the fact isn't reliable.

Current method: photograph each open spread in a single photo, both facing pages at once. Every row of data — date, aircraft, route, duration, landings, remarks — comes from one photo and one transcription pass, with nothing to match up afterward. A 10-photo test batch confirmed this reads just as clearly as single-page photos did.

Some rows in the table below are full flight-by-flight detail (date/aircraft/route per row); a few are still page-level totals (marked "page total, not itemized" in the remarks) from pages transcribed quickly to validate the method — those will get broken out row-by-row in a follow-up pass.

Bring new batches of photos to a Claude session to transcribe (handwriting reads far more reliably by having Claude look at the photo directly than through OCR software) — the results get added here as flights.

This page's data lives in a Cloudflare D1 database behind this site, so it stays up to date across visits and devices for anyone with the link. Use Export CSV any time to get the raw data out.
